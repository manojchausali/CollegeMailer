# CollegeMailer
Automatic mailer for colleges and university that sends emails on set date and time.

Developed an e-mail scheduler application named "College Mailer". Application schedules and sends emails on specified dates. 

## Features
- User login authentication
- Mail scheduling
- SMTP integration for sending emails,
- Database management.

## Technologies Used and Learnt
- Front-end Java Swing
- Back-end MySQL
- DateTimePicker
- Authentication
